# ingenieria_del_software_repositorio2
Sistema de Gestión de Incidencias ReparaCampus - Universidad Simón Bolívar
Prototipo de software desarrollado para la Universidad Simón Bolívar como parte del examen práctico de Ingeniería de Software I (SDD + IA).

## Integrantes
* Juan David Ávila León

## Descripción
Sistema web para la gestión, priorización y atención de incidencias de infraestructura en la universidad. Desarrollado con Python, Flask y SQLite.
